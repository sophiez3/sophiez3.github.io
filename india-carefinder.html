India CareFinder — Databricks Datathon 2026

Full-stack healthcare facility discovery and readiness ranking web application helping patients across India identify verified hospitals for urgent or planned medical procedures.

Application Demo Walkthrough

Video Walkthrough

Product Logic & Data Engineering Architecture

  • Context-Aware Readiness Weighting: Designed a dual-mode scoring framework that weights hospital readiness factors differently depending on whether a patient's need is an emergency or a planned procedure.
  • Cross-Source Geospatial Validation: Built a Databricks pipeline using PySpark and Spark SQL to clean raw facility records and cross-check coordinates against Indian PIN codes and external OpenStreetMap records to flag location discrepancies.
  • Explainable "How We Decide" Transparency: Engineered an evidence-extraction step in Spark SQL that pulls supporting quotes directly from hospital descriptions, surfacing transparent reasoning behind every recommendation in a dedicated "How We Decide" tab.
  • Live Databricks App Deployment: Powered the interactive frontend directly from curated Unity Catalog tables served via a Databricks SQL Warehouse.
